# 🚙 环球自驾六年计划（2026–2032）

从郑州出发、以「飞行 + 当地租车」为模式的分阶段环球自驾计划。

**在线浏览：<https://azl397985856.github.io/global-roadtrip/>**

## 计划概要

| 原则 | 说明 |
| --- | --- |
| 模式 | 洲际飞行 + 当地租车自驾（不做陆路横穿） |
| 节奏 | 每年走 1–2 个大区域，六年集齐六大洲 |
| 顺序 | 先国内练手 → 驾驶友好国家 → 高难度远征 |
| 强度 | 每段 10–16 天，每日驾驶 3–5 小时 / 300–500 km |
| 预算 | 不设上限（各段仍给出人均参考区间） |

## 本地开发

纯静态站点，无构建依赖：

```bash
cd global-roadtrip
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也可以运行（地图瓦片需联网）。

## 如何修改计划

所有行程数据集中在 `data.js`：路线坐标、逐日行程、签证策略、准备清单都在里面，改完刷新页面即生效。

## 目录结构

```
├── index.html   # 页面骨架
├── style.css    # 样式
├── data.js      # ★ 全部行程数据（唯一需要维护的文件）
└── app.js       # 交互逻辑（地图 / 时间线 / 弹窗 / 打卡 / 清单）
```
